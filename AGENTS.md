# Booking System — AGENTS.md

## Stack

- **PHP 8.4 / Laravel 13** — Inertia v3, React 19, Tailwind v4, Fortify v1, Wayfinder v0, Pint v1, PHPUnit v12
- **DB**: MySQL (dev), SQLite `:memory:` (tests)
- **Auth**: Laravel Fortify handles all auth routes/controllers. Don't create manual auth controllers.
- **Package manager**: npm (not pnpm despite `pnpm-workspace.yaml`)
- **Path alias**: `@/*` → `resources/js/*` (TypeScript + ESLint resolver)

## Key Commands

```sh
composer dev          # starts server + queue + logs + vite concurrently
composer lint         # pint --parallel (fix PHP style)
composer lint:check   # pint --parallel --test
npm run lint          # eslint --fix
npm run format        # prettier --write resources/
npm run types:check   # tsc --noEmit
php artisan test --compact                    # run all tests
php artisan test --compact --filter=testName  # single test
./vendor/bin/phpunit                          # CI-style (no --compact)
```

**After editing PHP**: run `vendor/bin/pint --format agent` to fix formatting.

## Tests

- `phpunit.xml` uses SQLite `:memory:` — no external DB needed to run tests.
- Every test class uses `RefreshDatabase`.
- Base `TestCase` provides `skipUnlessFortifyHas()` for feature-gated tests.
- Test files: `tests/Feature/Auth/`, `tests/Feature/Settings/`, `tests/Feature/DashboardTest.php`.

## Auto-generated / Gitignored Files

The following directories are gitignored and regenerated by Wayfinder — **do not edit directly**:
- `resources/js/routes/` — typed route functions
- `resources/js/actions/` — typed controller action functions
- `resources/js/wayfinder/` — Wayfinder internals

After adding/modifying routes: `php artisan wayfinder:generate`

## Frontend Layout Resolution

`resources/js/app.tsx` maps page component names to layouts automatically:
| Page name pattern | Layout |
|---|---|
| `welcome` | No layout (null) |
| `auth/*` | `AuthLayout` |
| `settings/*` | `AppLayout` + `SettingsLayout` |
| anything else | `AppLayout` |

## Lint / Format Config

- **Pint**: preset `laravel` (see `pint.json`)
- **ESLint** (`eslint.config.js`): ignores auto-generated dirs + `resources/js/components/ui/*` (Radix UI shadcn-style) + vite config. Requires blank lines around control flow statements. Enforces import ordering.
- **Prettier** (`.prettierrc`): `tabWidth: 4` (yml: 2), `singleQuote`, `prettier-plugin-tailwindcss` with `clsx`/`cn`/`cva` as tailwind functions.

## CI

- **lint.yml**: PHP 8.4 — `composer lint`, `npm run format`, `npm run lint`
- **tests.yml**: Matrix PHP 8.3/8.4/8.5 — `cp .env.example .env`, `php artisan key:generate`, `npm run build`, then `./vendor/bin/phpunit`

## MCP (Laravel Boost)

`opencode.json` configures Boost MCP via `php artisan boost:mcp`. Available tools:
- `database-query` (read-only SQL)
- `database-schema` (table structure)
- `search-docs` (version-specific package docs — run before making changes)
- `browser-logs` (frontend browser logs)
- `get-absolute-url` (resolve site URLs)

## Rate Limiting

- Login: 5 requests/min per email+IP (`config/fortify.php`)
- Password update: 6 requests/min (`routes/settings.php` throttle:6,1)

## Misc

- **Dates**: `CarbonImmutable` globally (see `AppServiceProvider`)
- **Destructive DB commands**: prohibited in production
- **Password rules**: prod requires 12+ chars, mixed case, symbols, uncompromised; dev has no constraints
- **Cookies**: `appearance` and `sidebar_state` are not encrypted
- **Wayfinder vite plugin** (`vite.config.ts`): `formVariants: true` enables `.form` method generation
- **React compiler**: babel-plugin-react-compiler enabled in vite config
